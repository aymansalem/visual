Target Application: European Patent Application EP 4523100.3 / PCT/US2023/019103 ("Split Stay Ranking and Matching")

Applicant: Airbnb, Inc.

Prior Dispute Citation: Kayak Dispute (2024) regarding split-stay accommodation search systems and algorithmic multi-segment itinerary matching.

Coherent Evidentiary Chain

  1. ANNEX-V-001, ANNEX-V-018, ANNEX-V-019 — The database and admin panel store account-level and hotel-level relocation permissions.
  2. ANNEX-V-007, ANNEX-V-017, ANNEX-V-019 — The system has database fields and administrator settings to enable relocation.
  3. ANNEX-V-002, ANNEX-V-003, ANNEX-V-004, ANNEX-V-006 — The user-facing interface describes room relocation and hotel relocation.
  4. ANNEX-V-005, ANNEX-V-010, ANNEX-V-011 — The backend reads relocation parameters and applies account-level permissions.
  5. ANNEX-V-008, ANNEX-V-012, ANNEX-V-014, ANNEX-V-016 — The system activates relocation, searches segments, and builds a combined booking.
  6. ANNEX-V-009, ANNEX-V-013, ANNEX-V-015 — Booking records and public demonstrations corroborate the transactional workflow.
  7. ANNEX-V-002, ANNEX-V-004, ANNEX-V-008 — The result is presented through the search-result renderer.
